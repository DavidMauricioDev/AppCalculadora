Aplicativo de calculadora para Android desenvolvido em **Java**, com o objetivo de praticar lógica de programação e aprender os fundamentos do desenvolvimento de aplicações mobile.

Este projeto faz parte da minha jornada de aprendizado em programação, aplicando conceitos teóricos na construção de uma aplicação prática.

## 📱 Sobre o projeto

O AppCalculadora tem como proposta oferecer uma interface para realizar operações matemáticas por meio de um dispositivo Android.

O desenvolvimento permite praticar a integração entre a interface gráfica e a lógica implementada em Java, além de explorar os recursos disponibilizados pela plataforma Android.

## ✨ Funcionalidades

- 🔢 Entrada de valores numéricos.
- ➕ Operações matemáticas.
- ➖ Subtração de valores.
- ✖️ Multiplicação.
- ➗ Divisão.
- 📱 Interface gráfica para interação com o usuário.

*As operações e os recursos efetivamente disponíveis dependem da implementação atual do aplicativo.*

## 🚀 Como executar o projeto

### 1. Pré-requisitos

Para abrir e executar o aplicativo, você precisará de:

- [Android Studio](https://developer.android.com/studio?hl=pt-br).
- Android SDK compatível com o projeto.
- Emulador Android ou dispositivo físico compatível.

### 2. Clone o repositório

Abra o terminal e execute:

```bash
git clone https://github.com/DavidMauricioDev/AppCalculadora.git
```

### 3. Acesse a pasta do projeto

```bash
cd AppCalculadora
```

### 4. Abra no Android Studio

1. Inicie o Android Studio.
2. Selecione a opção **Open**.
3. Escolha a pasta do projeto.
4. Aguarde a sincronização do Gradle.
5. Verifique se todas as dependências e versões necessárias estão configuradas.

### 5. Execute o aplicativo

1. Selecione um emulador ou dispositivo Android.
2. Aguarde a compilação.
3. Clique em **Run ▶** para executar o aplicativo.
